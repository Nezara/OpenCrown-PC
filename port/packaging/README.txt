OpenCrownPC test build (no game files included - you need your own dump)

1. Unzip anywhere. Run "OpenCrownPC Launcher.exe".
2. First start: choose where your saves go (default is fine).
3. Game page: pick the folder holding your own dump (eboot.bin + the .CPK files).
4. Online page: set your player name. Friends: copy your friend code, send it to the
   other player, add theirs, accept the request. "Test connection" checks the lobby.
5. Press PLAY. Go online from the game's own online menu.

Updates: from v1.0.1 on, the Update button (bottom left of the launcher) checks for a new
version, shows what it fixes and installs it. Coming from v1.0: download v1.0.1 once by hand.

Problems: Report a Bug page (Preview shows what is sent), or send
Documents\Dragons Crown Pro\logs\last_run.log.
If Windows SmartScreen warns: More info -> Run anyway. Allow the firewall prompt
(private + public) or the direct connection between players won't work.
